# Апельсин и ананас для VSeeFace

Две оригинальные стилизованные модели фруктов с лицами, без видимых рук и ног.

## Файлы

- `models/orange.vrm` — апельсин с листиком.
- `models/pineapple.vrm` — ананас с зелёной короной.
- `models/*.blend` — редактируемые исходники Blender 4.3.
- `previews/*.png` — изображения моделей на прозрачном фоне.

Формат: VRM 0.0. Внутри — невидимый гуманоидный скелет в T-позе. Геометрия привязана к голове, поэтому фрукт должен поворачиваться вместе с головой пользователя. Добавлены пресеты Blink, Blink_L, Blink_R, A/I/U/E/O и Joy. Это первая версия: взгляд отдельно от головы, физика листьев и дополнительные эмоции не реализованы.

## Открытие в VSeeFace

1. Скачайте нужный `.vrm` на Windows-компьютер.
2. В выборе аватара VSeeFace нажмите **Add avatar** и выберите файл.
3. Выберите камеру и микрофон, запустите отслеживание и выполните калибровку.
4. Проверьте повороты головы, моргание и открытие рта. При необходимости настройте чувствительность моргания и lip sync в VSeeFace.

VSeeFace в облачной Linux-среде не запускался. Структурные проверки файлов не заменяют проверку импорта и трекинга в самом приложении. При проблемах сохраните текст ошибки и версию VSeeFace.

## Повторная сборка

Из корня существующего репозитория (отдельный worktree не требуется):

```sh
blender -b --factory-startup --python-exit-code 1 --python tools/build_models.py
python tools/validate_models.py
```

Сборка перезаписывает сгенерированные файлы в `models/` и `previews/`; сначала сохраните ручные изменения исходников. Использует встроенный экспорт glTF Blender, затем добавляет метаданные, гуманоидный скелет и пресеты VRM 0.0. Дополнительные расширения Blender не нужны.

Модели экспортированы с метаданными CC0 и разрешением коммерческого использования.

## Выполненные проверки

- Сборка обеих моделей и рендер превью в Blender 4.3.2: успешно.
- `tools/validate_models.py`: обе модели прошли проверки контейнера, скелета, привязки геометрии и 9 пресетов мимики.
- Khronos glTF Validator: 0 ошибок у каждой модели. По 5 предупреждений: стандартное для VRM 0 имя расширения `VRM` и 4 вложенных skinned mesh. Их родитель — арматура без дополнительного преобразования. Валидатор glTF не проверяет само расширение VRM; отчёты находятся в `validation/`.
- Апельсин: 27 478 треугольников; ананас: 34 546.
- Импорт в VSeeFace и трекинг камерой: не выполнялись.
