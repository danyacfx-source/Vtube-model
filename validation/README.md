# Проверки моделей

## Мультяшный ананас версии 7.1

- Удалён румянец; круглые детские глаза заменены вытянутыми глазами с уменьшенными радужками, тонкой обводкой и более низкими бровями.
- Верхняя корона распределена между шестью spring bones; основания остаются привязаны к голове, а влияние постепенно возрастает к концам листьев.
- VRM secondary animation содержит одну группу из шести костей. Гуманоидный список по-прежнему состоит только из 19 стандартных костей.
- Структура VRM, все 16 выражений и пересечения лица с кожурой проверены успешно.

## Мультяшный ананас версии 6

- Фотографические глаза и губы заменены непрозрачной геометрией: белки, радужки, зрачки, блики, брови, полость рта, зубы и язык.
- Проверка VRM подтверждает, что материалы лица непрозрачны и не используют фотографические текстуры. Текстуры кожуры и листвы сохранены.
- 19 костей, 16 пресетов; неподвижные части одного выражения могут иметь нулевые morph deltas, но каждое выражение обязательно двигает хотя бы одну часть соответствующей сетки.
- Отрендерены нейтральное лицо, A/I/U/E/O, моргание, четыре направления взгляда, эмоции и сочетание Joy + Blink (`previews/pineapple-cartoon-*.png`).
- `validate_models.py`, `check_face_clearance.py` и повторный импорт экспортированного VRM — успешно. Khronos glTF Validator: 0 ошибок; предупреждения подробно перечислены в `pineapple-validation.json`.
- Количество треугольников ананаса: 107 792. Проверки VSeeFace на Windows и физической камеры в этой Linux-среде не проводились.

## Ананас версии 5 для VSeeFace

- Обновлён только ананас; апельсин и браузерное приложение с живыми глазами остались в прежних версиях.
- `validate_models.py`: 19 костей, 16 непустых пресетов, включая четыре направления взгляда, `lookAtTypeName=BlendShape`, автономные встроенные текстуры — успешно.
- Отрендерены нейтральный закрытый рот, A/I/U/E/O, Blink, четыре направления взгляда и Joy: `previews/pineapple-vseeface-*.png`.
- `check_face_clearance.py`: все отдельные shape keys, в том числе новый нейтральный рот и взгляд, проверены относительно кожуры; ошибок нет.
- Повторный импорт и рендер экспортированного VRM: `pineapple-roundtrip.png`.
- Khronos glTF Validator: 0 ошибок, 5 прежних предупреждений (историческое имя VRM и вложенные skinned mesh). Подробности — `pineapple-validation.json`.
- VSeeFace на Windows и физическая камера не запускались: автоматические проверки не заменяют проверку в приложении.

## Исходная версия 4

- Blender 4.3.2: обе модели собраны, исходники сохранены; нейтральный вид, три четверти и Joy отрендерены.
- Отдельно отрендерены A, I, U, E, O, Blink, Sorrow и Angry для каждой модели.
- `validate_models.py`: контейнер, 19 костей, skinning, 12 непустых пресетов, встроенные текстуры и карты нормалей/шероховатости — успешно.
- Для каждой лицевой сетки проверены `alphaMode=BLEND` и фактические значения альфа-канала `COLOR_0`: есть как полностью прозрачные, так и непрозрачные вершины. Одного наличия атрибута для этой проверки недостаточно.
- `check_face_clearance.py`: проверены центры видимых лицевых полигонов во всех отдельных shape keys относительно реальной поверхности кожуры. Пересечений глубже допуска 0.001 единицы модели не обнаружено. Дополнительно проверено направление нормалей чешуек ананаса.
- Khronos glTF Validator: 0 ошибок и 5 предупреждений на модель. Одно предупреждение связано с историческим именем расширения VRM; четыре — с вложенными skinned mesh под арматурой без дополнительной трансформации.
- Материалы используют официальный VRM 0 режим `VRM_USE_GLTFSHADER`. Тангенсы сохранены для материалов с normal map; для остальных материалов они не нужны и не экспортируются в итоговом payload.
- Апельсин: 61 040 треугольников. Ананас: 99 600 треугольников.
- `render_exported.py` импортирует glTF payload конечных VRM и рендерит его вместо исходных сеток; результат хранится в `*-roundtrip.png`. Это проверка экспорта, не запуск VSeeFace.
- VSeeFace, камера, микрофон и реальные горячие клавиши эмоций: не проверены в Linux-среде.
