# Проверки версии 3

- Blender 4.3.2: обе модели собраны, исходники сохранены, нейтральные выражения и Joy отрендерены.
- Отдельно отрендерены A, I, U, E, O, Blink, Sorrow и Angry для каждой модели.
- Проверка контейнера, 19 костей, skinning, 12 пресетов с непустыми morph targets и встроенных PNG-текстур, карт нормалей и их привязки к MToon: успешно для обеих моделей.
- Khronos glTF Validator: 0 ошибок, 5 предупреждений на модель. Одно предупреждение относится к историческому имени расширения VRM; четыре — к вложенным skinned mesh. Родитель этих mesh — арматура без дополнительной трансформации. Валидатор не проверяет расширение VRM; его ограничения не скрыты.
- Апельсин: 74 912 треугольника. Ананас: 83 520 треугольников.
- VSeeFace, камера, микрофон и реальные горячие клавиши эмоций: не проверены в Linux-среде.

JSON-отчёты содержат результаты текущих файлов версии 3.

- Карты микрорельефа экспортированы вместе с тангенсами: предупреждений о недостающем tangent space нет.
